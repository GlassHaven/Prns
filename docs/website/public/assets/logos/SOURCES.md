# Logo sources

`mediatek.svg` uses the [Simple Icons MediaTek artwork](https://cdn.simpleicons.org/mediatek), retrieved 2026-10-05. The SVG viewBox is cropped to the existing artwork and the fixed fill is omitted so the site's monochrome mask can follow the surrounding text color. Paths and proportions are unchanged.

MediaTek's [brand assets](https://www.mediatek.com/brand-assets) document the parallelogram mark. It identifies the MT7628 processor vendor on the ThinkNode G4 and Heltec HT-HD01-V2 cards. The logo remains MediaTek's trademark and is used only to identify compatible hardware, without implying endorsement.
